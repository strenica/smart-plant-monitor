# COMPRESSED TIMESCALE. The intervals below are shorter than the deployed
# ones so that a single 60 s capture contains three of whatever this variant
# does. The Monsoon resets every minute, so a capture cannot be longer, and
# at the real intervals a 60 s window would contain one event or none.
#
# The cost of that: the energy per hour here is NOT the deployed figure. It
# is the idle cost plus three events. Divide the event part by three to get
# the per-event cost, then compose for the real interval:
#
#     E/hour(real) = idle + events_per_hour(real) x event_cost
#
# measurement/README.md has the arithmetic.
#

# buzzer. v3_event.txt is the exception.
